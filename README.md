# Reels website

Веб-приложение на **React** ([Create React App](https://github.com/facebook/create-react-app)): макет из **Figma**, разработка с [Cursor](https://cursor.com).

## Запуск

```bash
npm install
npm start
```

Откроется [http://localhost:3000](http://localhost:3000).

## Сборка

```bash
npm run build
```

Результат в папке `build`.
